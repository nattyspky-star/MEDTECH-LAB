# MedTech Quick Reference

คู่มืออ้างอิงงานเทคนิคการแพทย์ — ค่าอ้างอิง ค่าวิกฤต ขั้นตอนการตรวจ QC
**+ แอตลาสภาพใต้กล้องจุลทรรศน์ 126 ภาพ + โหมดฝึกระบุ (Quiz) + Flowchart การระบุเชื้อ/เซลล์ 11 แผนผัง**
ใช้งานบนมือถือได้ และใช้ออฟไลน์ได้หลังเปิดครั้งแรก

## ไฟล์ในโฟลเดอร์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | แอปหลัก + ข้อมูลรายการตรวจทั้งหมด |
| `atlas.js` | แอตลาสกล้องจุลทรรศน์ (ภาพวาด SVG + จุดสังเกต + Quiz) — โหลดเมื่อเปิดหน้าแอตลาส |
| `flow.js` | Flowchart การระบุเชื้อ/เซลล์ — โหลดเมื่อเปิดหน้า Flowchart |
| `sw.js` | Service worker สำหรับใช้งานออฟไลน์ |
| `manifest.webmanifest`, `icon*.png`, `icon.svg` | ไอคอนและการ “เพิ่มลงหน้าจอหลัก” |
| `.nojekyll` | ให้ GitHub Pages เสิร์ฟไฟล์ตรง ๆ |

## วิธีเผยแพร่ด้วย GitHub Pages (ทำจากมือถือหรือคอมก็ได้)
1. เข้า https://github.com → **New repository** → ตั้งชื่อ เช่น `medtech-ref` → เลือก **Public** → Create
2. กด **Add file → Upload files** → ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (รวม `.nojekyll`) → **Commit changes**
3. ไปที่ **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → **Save**
4. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/medtech-ref/`
5. บนมือถือ เปิดลิงก์ → เมนูเบราว์เซอร์ → **Add to Home Screen / เพิ่มลงในหน้าจอหลัก** เพื่อใช้เหมือนแอป

> ไฟล์ทุกไฟล์ต้องอยู่โฟลเดอร์เดียวกัน · ถ้าเปิด `index.html` ตรงจากเครื่อง (file://) บางเบราว์เซอร์จะโหลดแอตลาส/ออฟไลน์ไม่ได้ — ให้เปิดผ่าน GitHub Pages

## อัปเดตเนื้อหา
- แก้รายการตรวจ: `index.html` ส่วน `const SECTIONS`
- เพิ่มภาพแอตลาส: `atlas.js` (แต่ละรายการมี `key` จุดสังเกต, `diff` แยกจาก, `sig` ความสำคัญ, และ `draw()`)
- เพิ่ม/แก้ Flowchart: `flow.js` ส่วน `const FLOWS`
- หลังอัปโหลดไฟล์ใหม่ ให้เปลี่ยน `VERSION` ใน `sw.js` (เช่น `mtq-v2.0.1`) เพื่อให้มือถือโหลดเวอร์ชันใหม่

## ข้อจำกัด
ภาพในแอตลาสเป็นภาพวาดประกอบที่เน้นจุดสังเกต ไม่ใช่ภาพถ่ายจริง · ค่าอ้างอิงเป็นค่าทั่วไป ต้องใช้ค่าของห้องปฏิบัติการตนเอง · ไม่ใช่เครื่องมือแพทย์
